Agent Guide

FAQ and Example Prompts

Use this page to understand what the agent can answer, which questions work well, and how follow-up prompts should be phrased for inventory, cost, MCP, and maker-checker workflows.

Recommended Questions

Cost and Inventory FAQ

How do I ask for total AWS cost?

Use direct billing language. Example: Fetch me the total cost of all resources in my AWS account.

How do I ask for service-level cost detail?

Ask a follow-up like Can you produce an itemized breakup? after the total is returned.

How do I ask for region-wise inventory?

Use Please fetch me a list of all active resources on my account and group them per AWS region.

Can I drill into one region?

Yes. Example: Are there any ECR or ECS resources on my account in region ap-south-1?

Capabilities and MCP FAQ

How do I ask what the agent can do?

Try What can you do for me? or What are your capabilities?

How do I inspect the active MCP tool surface?

Use Give me a list of all MCP tools that are active for this agent.

Can the answer change by selected MCP server?

Yes. The available tools depend on the MCP server selected in the Runtime panel.

Maker-Checker FAQ

How do I ask about approvals?

Use How does maker-checker workflow work?

When is approval required?

Mutating AWS actions can be queued for approval based on the active profile and current checker configuration.

What happens after approval?

The queued tool call is executed with the approved arguments. Approval does not regenerate the request from scratch.

Prompting Tips

Be explicit about scope

Say all resources, per region, or the exact region name when you want precise inventory results.

Use follow-up prompts naturally

Once the agent returns a summary, ask for a breakup, filter, or region-specific deep dive in the next message.

Ask capabilities before mutation

If you are unsure which tools are active, ask for capabilities or MCP tools first, then request the operation.
